# Salary Prediction Application

A pre-generation architecture app that predicts data science salaries using a Decision Tree model, generates LLM-powered narratives via Ollama, and displays results on a Streamlit dashboard backed by Supabase.

## Setup

```bash
# Clone repo
git clone <repo-url>
cd salary-prediction-app

# Create virtual environment
python3.11 -m venv .venv

# Install dependencies
pip install -r requirements.txt
